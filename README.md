## Stonks Bot

This is code for a stock-simulation Discord bot game, called Stonks Bot. I made it when I was very new to programming, in 2023. There are many decisions I made in the code that I wouldn't make now. For example, the variable names are quite random at times, and some of the function logic is inefficient. Regardless, it is a bot that works and works well, and I am proud of it.

Tech Stack: Python, matplotlib
